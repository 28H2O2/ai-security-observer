# 0.4.0 验证记录

验证日期：2026-10-27。数据快照仍为 2026-10-23；没有新增事实记录。

## 已验证

- 数据与功能共 24 项 Node 测试：既有 PDF/CVE/来源/筛选回归，以及每日/每周归档、跨年、闰日、无效日期、空日期、排序、去重、导出一致性、RSS 转义和生产 SITE_URL 拒绝规则。
- PowerShell XML 解析器成功读取 RSS 2.0，共 50 条；本地构建明确标记“本地预览”。
- 本机 HTTP 服务验证 14 个页面、脚本、样式、数据与图片入口全部返回 200；JS、JSON、XML、PNG 的 MIME 类型正确；ES module 引用目标均存在且同源。运行时资源不依赖第三方请求。
- 浏览器离线副本加载全部 76 条实际构建数据。跨年周报范围 2025-12-29 至 2026-01-04 显示 0 条；2026-10-19 至 2026-10-25 周报显示 5 条。
- SSMS + Embrace The Red + 提示注入组合筛选显示 2 条，实际点击导出的 JSON 含相同两条与筛选参数；输入不存在关键词后立即导出得到 0 条，验证了搜索防抖期间的数据一致性。
- 实际触发周报 Markdown 生成，包含日期范围、分组、影响、建议及证据。浏览器测试截取 Blob 内容检查，未依赖系统下载对话框。
- 390px 与 320px 移动端截图人工查看；320px 的列表、周报、来源图和详情均无页面横向溢出，邮箱完整留在边界内。1280px DOM 尺寸检查无溢出，Logo 宽 240px。

## 验证方式与限制

预览浏览器实际位于远端 Mac，不能连接 Windows 的本地回环地址。因此 UI 检查使用相同 HTML、CSS、JS、Logo 和全部 JSON 构建产物的离线副本；模块组合后执行，fetch、location/history 和下载被测试适配器替换。没有修改发布包的网络行为。该测试验证 DOM、布局和交互逻辑，不等价于原生 ES module 网络加载、系统保存文件或真实浏览器地址栏导航的端到端验证。

桌面截图获取超时，桌面仅完成 DOM 布局检查；手机截图已取得并检查。实际运行测试使用环境自带 Node 24.19.0，项目声明目标仍为 Node 22；未安装额外运行依赖。

环境未安装 Nginx，因此未执行 nginx -t。香港服务器、正式域名和 TLS 证书尚未提供，未部署，未完成电信/联通/移动的无代理访问验收。部署步骤和待验收表位于 deployment/README.md。
